## 保存与恢复的边界

v1.1 的“一键还原增益并保存”只撤销数字增益调整，恢复为开发样机首次修改前读到的 0 dB。其余参数保留当前设备值，不会从演示数据或别人的配置覆盖 EQ。它串联备份、应用、回读、提交、关闭句柄后重连读取；提交命令不自动重发。

用户反馈修改增益后官方 App 识别不到设备。目前只读检查显示设备 VID/PID、内部版本、控制模式及已知 EQ 未变；尚不能据此确定 App 无法识别的原因，也未验证还原后能否恢复官方 App 连接。没有经过验证的官方出厂重置协议，故不提供完整出厂重置。

“应用”先备份，再写入差异，逐项回读，并检查其他已知配置是否保持原值。“保存到耳机”是独立操作，提交当前已应用的配置，随后尝试重新读取。

保存成功后的回读只能确认当前设备状态。要验证断电保留，需要真实拔插后再次读取或换接另一台主机验证。

备份仅包含工具已知的音频参数，不是固件镜像。多参数应用途中出错时可能已有部分参数生效，工具不会自动恢复到旧值；应先重新读取实际状态，再决定下一步。

不提供固件升级、设备标识修改、任意寄存器写入，也不会为测试而自动播放音频。
