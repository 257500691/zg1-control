ZG1 Control 1.0 · 竹林鸟 ZG1 Ultra 调音工具
================================================

打开方式
--------
先完整解压，再双击 ZG1-Control.exe。
适用于这副 USB 31C2:1102、内部版本 V1.0.2 的 ZG1 Ultra。
使用 Windows 自带 .NET Framework 和 HID 驱动，无需安装 Python、其他驱动或联网。
如果耳机仍接在 iPhone 上，先把它接回 Windows 电脑。

基本流程
--------
1. 点“连接并读取”，从耳机读取当前值。打开程序不会自动连接或写入。
2. 编辑参数；此时只是修改编辑区，音乐不会立即变化。
3. 点“应用修改”，核对变更清单后应用。工具会先自动备份，再写入并回读。
4. 需要断电保留时，点“保存到耳机”。USB 可能短暂重新连接。
5. 保存后拔插耳机，再点“连接并读取”，可核对断电后的实际状态。

工具启动时不会覆盖设备现有设置，也不会自动套用 −12 dB。
请先连接读取，再导出你自己的配置，作为调整前的备份。
点“演示”可在不连接耳机的情况下熟悉界面；演示里的操作只改内存。

可调参数
--------
总览与增益：全局数字增益（0.5 dB 步进）、播放模拟 PGA 档位。
播放 EQ：五段频率、增益、Q、滤波类型，以及播放 EQ 开关。
麦克风 EQ：麦克风数字/模拟增益，五段参数和 EQ 开关。
动态处理：噪声门开关、关门电平、开启/关闭阈值、启动/释放/噪声判定时间；
          限幅器开关、软拐点、阈值、启动/释放时间。
备份与导入：导出设备当前配置；导入同型号、同固件配置到编辑区。
寄存器与日志：只读查看已知寄存器与收发日志，方便核对。

数字增益显示开源编码范围 −64 至 +63.5 dB；正增益会减少削波余量。
播放模拟档位为静音、−18 至 +3 dB；麦克风模拟档位按开源表显示。
EQ 编辑限制为 20–20000 Hz、−12 至 +12 dB、Q 0.05–20。
读取时保留原始编码值，不会自动修正设备已有参数。
曲线是标准 RBJ 滤波器在 48 kHz 下的示意，不是耳机实测频响或固件内部计算结果。

验证范围
--------
本机已验证：HID 读取、全局数字衰减、配置提交，以及换接 iPhone 后衰减仍生效。
本工具 EXE 已完成真实设备的全参数只读检查。
麦克风、模拟增益、不同 EQ 滤波类型、噪声门和限幅器，按开源协议实现，
并通过模拟编码/掩码/写入流程测试，未为测试而改动这副耳机，也未逐项听测。

只调整总音量时，只需改“全局数字增益”，其他参数不会重写。
“数字增益”在本机已证实能整体降低音量；其确切位于 EQ 前还是 EQ 后未测量。
此版针对当前硬件和固件，其他版本只读查看，不开放写入。
没有固件升级、设备 ID 修改、任意寄存器写入或自动更新功能。

备份和故障处理
--------------
每次应用/保存前，在 EXE 同目录的 data/backups 创建参数备份。
备份失败会停止，不继续写入。请把解压后的文件夹放在你能写入的位置。
data/last-session.log 保留最近一次操作日志；演示备份在 data/demo-backups。
这些文件只覆盖工具已知的音频参数，不是完整固件备份。

其他调音程序改动耳机参数后，请先重新读取再编辑，避免覆盖其他程序的修改。
若应用中途发生 USB 断开或回读不一致，可能已有部分参数即时生效，工具不会继续保存。
此时重新连接并读取，再决定是否导入之前的备份到编辑区。
若提示“保存指令已发送，但未能重新读取”，不要反复点保存；拔插后先读取核对。
应用或保存前暂停播放；提高增益时从较低系统音量开始试听。
